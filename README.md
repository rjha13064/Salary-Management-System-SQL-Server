# Salary Management System - SQL Server

## Project Overview

The Salary Management System is a SQL Server based database project developed to manage employee, department and salary-related information.

The project demonstrates SQL concepts used for employee salary analysis, department-wise reporting and salary history analysis.

## Tools & Technologies

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## Database Structure

The project contains four main tables:

- departmentdetails - stores department information
- employeedetails - stores employee information
- salarydetails - stores current salary information
- salaryhistory - stores employee salary changes and increments
